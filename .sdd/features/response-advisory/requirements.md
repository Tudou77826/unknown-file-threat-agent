# Response Advisory Requirements

## 目标

基于研判结论、资产上下文和组织策略提出安全、可执行的候选处置方案，并明确业务影响、前置条件、审批和回滚。

## 功能要求

- 接收不可修改的 `JudgmentResult`。
- 补充资产关键度、所有者、环境、业务依赖和现有控制状态。
- 从 RAG 获取有效 SOP、审批矩阵、取证要求和操作手册。
- 比较多个候选动作，而不是只返回单一命令。
- 输出优先级、目标、理由、影响、可逆性、前置条件、审批、回滚和验证步骤。
- 对未知影响或上下文不足给出条件化建议。

## 非目标

- 不重新判定案件事实。
- 不直接调用隔离、删除、禁用或封禁动作。
- 不以通用最佳实践覆盖组织明确政策。

## 验收条件

- 同一威胁在生产资产和测试资产上可以生成不同的风险与审批建议。
- 每个动作均引用 Judgment、资产事实或政策来源。
- 缺少关键业务上下文时不会生成无条件高风险动作。
