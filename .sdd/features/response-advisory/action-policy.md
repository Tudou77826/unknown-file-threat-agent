# Response Action Policy

## 风险分级

| 类别 | 示例 | 默认处理 |
|---|---|---|
| 读取与补充 | 查询、生成工单、通知 | 可自动 |
| 低影响阻断 | 临时阻断单一恶意端点 | 策略允许时自动或快速审批 |
| 主机控制 | 杀进程、终端隔离 | 依置信度和资产类型审批 |
| 身份控制 | 禁用账号、吊销会话 | 默认人工审批 |
| 破坏性动作 | 删除文件、停止生产服务 | 强制人工审批 |

## 校验规则

- 动作必须位于执行系统白名单。
- 目标必须属于当前案件和审批 Scope。
- 必须检查生产属性、关键业务、共享账号和证据保全要求。
- 高风险动作必须有回滚方案；不可逆动作必须明确说明。
- 建议过期后不得直接执行，必须重新评估上下文。
