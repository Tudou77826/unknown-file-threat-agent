# Authorization and Approval

## 双重约束

Agent Policy 决定任务应该访问什么；数据平台和执行系统的身份权限决定调用实际能够访问或执行什么。两者必须同时满足。

## Scope

Scope 至少包含租户、Workspace、主机、实体、数据域、时间范围和动作类型。扩大 Scope 必须说明依据、候选目标和有效期。

## 审批

- 数据扩域与动作审批分开。
- 审批人必须具备对应资源和动作权限。
- 高风险动作支持职责分离和双人审批。
- 审批绑定具体 ResponsePlan 版本和动作参数；计划变化后原审批失效。
- 拒绝、超时和撤回均写入案件并反馈给处置建议循环。
