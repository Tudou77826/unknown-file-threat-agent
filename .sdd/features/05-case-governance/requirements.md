# Case Governance Requirements

## 功能要求

- 从告警、人工操作、定时任务或外部事件创建案件。
- 保存案件状态、研判运行、处置建议、审批和执行结果。
- 支持暂停、恢复、取消、重试、人工补充和超时结束。
- 管理租户、用户、Agent 身份、数据 Scope 和动作 Scope。
- 为跨主机、跨 Workspace 和高风险动作提供审批。
- 为工具、模型、知识、策略、审批和执行建立统一审计链。

## 非目标

- 不自行解释安全证据。
- 不替代底层数据平台 RBAC。
- 不允许审批结果反向篡改研判事实。

## 验收条件

- 进程重启后案件可以从最后一致状态恢复。
- 相同幂等键不会重复执行副作用动作。
- 未授权用户不能读取案件、批准动作或扩大 Scope。
