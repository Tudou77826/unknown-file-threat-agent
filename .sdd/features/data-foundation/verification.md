# Data Foundation Verification

## 契约测试

- 每个 Connector 使用相同规范化 Case 验证字段语义。
- 查询 API 验证时间、实体、主机、分页和过滤组合。
- Schema 版本升级验证向后兼容或迁移路径。

## 数据质量测试

- 时间、主机、进程和文件关联键完整性。
- 原始记录引用可访问性。
- 重复、乱序、迟到和缺失事件处理。
- Coverage 与实际源数据可用范围一致。

## 权限测试

- 跨租户和跨 Workspace 查询必须失败。
- 行级 Scope 不能通过过滤参数绕过。
- 查询和失败访问均写入审计。

## 当前原型基线

现有 18 个 Case 可继续作为 Repository 契约的初始回归集，但不能代替真实数据规模、延迟和权限测试。
