# Replay 遥测采集范围（对齐态势感知探针）

## 决策

Replay 原始遥测由**自建采集**（auditd / eBPF 类）产生，采集范围对齐态势感知系统探针；探针导出可用后可再评估切换。在此范围之外，自建采集**额外补充环境基线数据**（见映射表），否则 AI 侧只有黑证据、没有白证据，误报率会虚高。

## 对齐的探针采集范围

1. **进程**（最完整）：启动/退出、命令行、PID、父进程链、UID/GID 与提权前后对比、可执行文件路径与 Hash、脚本路径与 Hash（⚠️ 入库时丢失）、容器 ID/镜像/Namespace、登录会话关联、VM 逃逸信息。
2. **文件**：创建/修改/删除事件、路径、操作类型与结果、操作进程 PID 与路径、容器上下文。**不采集**：文件内容 Hash、文件大小、文件读取事件、重命名事件。
3. **网络**：TCP/UDP 四元组、方向、协议、连接状态、关联进程 PID。**不采集**：传输字节数、DNS 查询。
4. **系统调用**：关键 syscall（execve、mount、clone、setuid 等）、参数、结果、调用进程、容器上下文。
5. **登录认证**：OS / DB / OM 运维登录的用户名、来源 IP、成败、用户类型/域。
6. **账号管理**：OS 与 OM 账号的创建/删除/修改、目标用户、变更前后值。
7. **命令执行**：用户执行的 shell 命令、类型与参数（密码脱敏）、源/目标路径。
8. **文件传输**：SFTP 文件名、方向、字节数、关联用户与来源 IP。
9. **审计日志**：auditd 规则触发记录；间接覆盖 systemd/cron 操作（非结构化）。
10. **端口**：监听端口、绑定 IP、协议、端口→进程映射、端口扫描事件。

## 与 Canonical 数据模型的映射与缺口

| Canonical 事件族 / 数据 | 探针来源 | 对齐结论 |
|---|---|---|
| ProcessEvent | §1 进程 | 完整覆盖（超集，转换器做投影裁剪） |
| FileEvent（创建/写入/删除 + 操作进程） | §2 文件 | 事件覆盖；无内容 Hash、大小、读取事件 |
| 文件身份（File_hash 判定锚点） | §1 可执行文件 Hash | **仅被执行的文件有 Hash**（来自 exec 事件）；未执行的落盘文件进不了 File 记录模型；脚本 Hash 入库丢失 |
| NetworkSessionEvent | §3 网络 | 四元组/方向/进程归属覆盖；无字节数 |
| DnsEvent | —（不采 DNS） | **无来源**；C2 场景按 IP 直连构造，域名型 C2 / DNS 隐蔽通道不在可评测范围 |
| PersistenceEvent | §9 auditd + §2 文件写入 | 半结构化；转换器需规则化派生（unit write/enable、cron 写入等） |
| AuthenticationEvent | §5 登录认证 | 覆盖 |
| 账号变更 | §6 账号管理 | 探针有、Canonical 模型无对应事件族；PoC 避开账号持久化技术，模型扩展留给 Feature 01 |
| 反证数据（包归属、批准端点、资产基线） | —（不在十类内） | **无来源**；自建采集补充环境基线采集器：rpm/dpkg 包清单、CMDB 批准端点、监听端口基线，对齐现有 `counter_evidence` 的 `rpm-inventory` / `cmdb-baseline` 来源 |

## 对 Feature 19 的直接约束

- 判定对象文件的 Hash 以**进程执行事件**携带的可执行文件 Hash 为准 → 技术选择收紧为「落盘**并执行**」，优先 ELF 载荷（脚本 Hash 入库丢失，证据链弱）。
- 数据窃取类场景的证据链 = 文件写入 + 出站连接（无读取事件、无流量字节数），AI 的量级判断受限，预期结论按此校准。
- C2 / 网络类场景统一按 IP 直连构造，不依赖域名。
