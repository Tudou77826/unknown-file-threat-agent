# 标准攻击技术选择目录（步骤 02）

从 ATT&CK v19.2「Linux + 文件类可观测」池（205 条）中按步骤 02 约束选取：**Linux 可执行、落盘并执行（判定对象有 Hash 锚点）、单主机边界内、优先落盘载荷本身恶意的小体积 ELF**。每条恶意剧本刻意构造一个良性对照组（同类文件行为、合法来源），供误报率统计。
