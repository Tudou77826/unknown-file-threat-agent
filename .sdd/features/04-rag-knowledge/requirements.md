# RAG Knowledge Requirements

## 目标

让两个 LLM 循环获得与当前租户、场景和时间有效性一致的知识，并返回可审计引用。

## 功能要求

- 分开管理调查知识、组织处置策略和历史案件。
- 文档接入时保存来源、所有者、版本、生效时间、过期时间、密级和 ACL。
- 支持关键词、结构化过滤和向量语义的混合检索及重排序。
- 检索请求携带租户、身份、案件、使用目的和场景。
- 每个结果返回稳定知识 ID、片段、来源、版本、相关性和适用限制。
- 支持撤回、替代和重新索引过期知识。

## 非目标

- 不使用向量检索替代高容量安全日志查询。
- 不允许历史案件结论自动成为当前 Verdict。
- 不允许公共威胁知识覆盖组织内部有效政策。

## 验收条件

- 未授权文档不会被召回或进入模型上下文。
- 过期政策不会支撑当前处置方案。
- 输出中的知识引用能够定位到具体版本和片段。
