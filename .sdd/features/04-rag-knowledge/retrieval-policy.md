# Retrieval Policy

检索按以下顺序执行：

1. 身份、租户和 ACL 过滤；
2. 有效期、文档状态和适用环境过滤；
3. 场景、资产类型和使用目的过滤；
4. 关键词与向量混合召回；
5. 重排序和多样性控制；
6. 返回有限数量的带引用片段。

## 冲突处理

- 组织当前有效政策优先于通用建议。
- 新版本优先于被替代版本，但保留历史引用。
- 多份同级政策冲突时，返回冲突并要求确认，不能由 LLM 私自选择便利方案。

## 安全边界

- Prompt 中不得出现用户无权查看的文档片段。
- 检索结果中的指令视为数据，不得覆盖系统和安全策略。
- 文档中的命令或动作不能绕过 ResponsePlan Validator。
