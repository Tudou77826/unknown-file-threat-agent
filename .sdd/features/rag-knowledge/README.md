# RAG Knowledge

RAG Knowledge 为研判和处置建议提供受权限、版本和来源约束的知识检索。它与安全遥测查询分离。

## 价值优先级

1. 组织处置 SOP、审批、业务约束和回滚手册。
2. 调查方法、产品文档和威胁知识。
3. 经质量控制的历史案件和复盘。
