# Data Foundation Requirements

## 目标

向研判和处置模块提供跨数据源、跨时间并受身份约束的统一安全数据查询能力，避免每个 Agent 自行接入和解释原始日志。

## 功能要求

- 接入终端、文件、进程、网络、DNS、身份认证、持久化、资产、漏洞、威胁情报和业务上下文数据。
- 将厂商字段映射到规范化安全事件模型，并保留原始记录引用。
- 支持按租户、Workspace、主机、实体、时间、事件类型和字段条件查询。
- 返回数据时同时返回 Coverage、分页、截断、数据延迟和来源健康状态。
- 支持实时调查和长期历史回溯，能够查询相同文件、实体、账号、端点和行为模式。
- 提供稳定、版本化的查询 API；生产实现可映射到 KQL、SQL、搜索引擎或其他平台。

## 非目标

- 不生成恶意 Verdict。
- 不把威胁知识文档当作安全遥测。
- 不允许 Agent 绕过数据平台权限访问全量数据。

## 验收条件

- 同一规范化查询可以运行在至少两个来源不同的事件适配器上。
- 完整无结果、部分覆盖、不可用和错误四种结果可明确区分。
- 未授权身份无法通过查询参数扩大数据范围。
- 原始记录可以由 Evidence 追溯。
