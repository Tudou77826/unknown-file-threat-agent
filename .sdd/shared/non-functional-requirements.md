# Non-Functional Requirements

## 安全与权限

- 数据访问同时受 Agent Scope 和底层数据平台身份权限约束。
- RAG 检索必须继承知识源 ACL，禁止越权召回。
- 高风险处置默认要求人工审批，密钥不得进入 Prompt、报告或日志。

## 可审计与可解释

- 记录模型、Prompt/Skill 版本、工具参数、证据引用、知识引用、策略结果、审批和执行结果。
- Verdict 和 ResponsePlan 必须能够回溯到输入证据或政策依据。

## 可靠性

- 工具调用必须具备超时、重试、幂等键和明确错误语义。
- 案件状态必须可持久化、恢复和安全重放。
- 模型不可用时应支持降级为确定性流程或人工调查。

## 性能与成本

- 实时数据和历史数据采用不同查询预算。
- LLM 上下文只包含与当前决策相关的状态和检索结果。
- 记录每个案件的数据查询、模型和执行成本。

## 质量

- 每个威胁场景至少包含恶意、良性和证据不足对照 Case。
- 模型、规则、Prompt、知识库或 Schema 更新必须运行回归评测。
